Streaming API Reference

The Streaming API lets you consume generated tokens as they arrive.

Authentication

Pass your API key in the Authorization header.

curl https://api.example.com/v1/stream \
  -H "Authorization: Bearer $ACME_TOKEN"

Endpoint

MethodPath
POST/v1/stream

Parameters

NameTypeRequiredDescription
modelstringyesModel id to stream from.
messagesarrayyesConversation messages.
temperaturenumbernoSampling temperature.

Options

  • stream_options.include_usage — append usage metadata
  • timeout — idle timeout in seconds

Returns

An SSE stream of delta objects.

data: {"delta":{"content":"Hello"}}
data: [DONE]

Examples

const stream = await client.stream({ model: "demo", messages });
for await (const delta of stream) {
  process.stdout.write(delta.content);
}
Note

Streams expire 10 minutes after the last event. Reconnect using the resume token.

Warning

Do not retry non-idempotent requests on timeouts without checking the server state.
